# Final project acceptance

LockIn 1.0.0 provides the complete local-first focus workflow: setup, ritual, monotonic timing,
pause/resume, overtime, local shortcuts, distractions, SQLite persistence, portable CSV, staged
import, confirmed-time recovery, sleep handling, quotes/sound, goals/dashboard, statistics/charts,
calendar heatmap, and advanced read-only history.

Operational SQLite is separate from portable CSV and immutable application resources. Unknown crash
time and temporary intentions never become focus history. Packaging is generated from sanitized
starter resources, never the live portable folder. Tests, coverage, integrity, packaged health,
installer lifecycle, checksums, and leak scans are required release gates.

Publication evidence:

- Release URL: `https://github.com/surabhi1914/lockin-desktop/releases/tag/v1.0.0`

- Installer/ZIP SHA-256: recorded in the verified GitHub Release `SHA256SUMS.txt`

Known limitations are Windows x64 support, unsigned binaries, and no auto-update, cloud sync,
Spotify, global hooks, kiosk/system blocking, or concurrent-device automatic conflict resolution.

The post-publication release checker is the authoritative verification that the private repository,
release commit, annotated tag, and exactly three approved release assets are present.

LockIn v1.0.0 is complete.
